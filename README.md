# Путь-24
Telegram-бот для одной–трёх ежедневных привычек: план на сегодня, отметки,
семидневная статистика, достижения и контекстный DeepSeek-коуч.

## Запуск
Python 3.12, из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В настройках среды задайте `TELEGRAM_TOKEN` (обязательно),
`DEEPSEEK_API_KEY` (опционально). Секреты не коммитьте.
Не запускайте два poller-процесса с одним токеном.
Исходящие HTTPS-домены: `api.telegram.org`, `api.deepseek.com`.
`PROXY_URL` — необязательный явный прокси для Telegram.

`DATABASE_PATH` переопределяет путь SQLite (по умолчанию `data/way24.sqlite3`).
SQLite сохраняет данные между перезапусками процесса. Для развёртывания
нужен постоянный диск, резервное копирование и один экземпляр приложения.
Облачная среда разработки не гарантирует круглосуточную работу.
Старое хранилище в памяти не имело файлов: автоматически восстановить его
после остановки нельзя. Supabase SQL-схема оставлена как исторический материал;
приложение её не использует.

## Сценарии
- `/start`: меню; настройки часового пояса (по умолчанию UTC) и стиля коуча.
- «Привычка»: название → единица → норма → срок (0 — без срока).
- «Сегодня»: выбрать привычку, добавить число, включая дробные километры,
  либо отметить оставшуюся дневную норму. Завершение сохраняет историю.
- «Неделя»: последние семь дней, включая незавершённый текущий день;
  знаменатель учитывает дату начала и срок каждой привычки.
- Серия увеличивается один раз за выполненную календарную дату. Вчерашняя
  серия остаётся текущей, пока сегодняшний день не закончился.
- Напоминание: один раз в сутки, только если есть незавершённые привычки.
  При старте после заданного времени может прийти запоздалое напоминание за сегодня.
- «Коуч»: последние цели, активные привычки, статистика и до восьми последних
  сообщений передаются DeepSeek. Стиль: спокойный/требовательный/жёсткий.
  Рекомендации AI не меняют план автоматически. Без ключа трекер работает.
- `/delete_data` → `/confirm_delete`: удалить личные данные из рабочей базы.
  Резервные копии удаляются отдельно администратором.

Изменение часового пояса влияет на новые отметки; прежние даты не пересчитываются.
Срок привычки считается в календарных днях, начиная с даты создания.
После истечения срока она исчезает из активного плана; история остаётся в базе.

## Структура и проверки
`bot/handlers.py` — интерфейс Telegram, `bot/store.py` — SQLite и правила учёта,
`bot/coach.py` — асинхронный клиент AI с тайм-аутом и ограничениями запросов.

```sh
.venv/bin/python -m unittest discover -s tests -v
```
